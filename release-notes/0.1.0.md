First release.

- **Log today's work**: for every configured repository, your commits since midnight (or since the last logged commit, when a day was skipped) are written under `## Code` in today's daily note as one sub-list per repository: totals, one line per commit with the files it touched and a link to the commit on GitHub, GitLab or Bitbucket, and a line for uncommitted changes. Re-running replaces the block; it never duplicates.
- **Weekly work report**: `Reports/Code week YYYY-Www.md` with a table of commits, lines, files and busiest day per repository, every commit grouped by day, and, when turned on, five bullets per repository written by a local Ollama model from the commit messages. Every hash the model cites is checked against the week's commits; invented ones are dropped. Also available for last week.
- **Scan TODOs**: `TODO`, `FIXME`, `HACK` and `XXX` comments across each repository (files git tracks or does not ignore), as a table per repository in `Code/TODOs.md` with `vscode://` or `idea://` links that open the file at the line. Optional age from `git blame`.
- **Open today's code block** and **Add a repository** (validated with git; name, remote and default branch read from the repository).
- Only commits by you are logged: the author list in settings, or each repository's `git config user.name` / `user.email`.
- Everything runs locally through `git`; the model is optional and sees commit messages only.
